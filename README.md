# Data-Analyst
This project focuses on analyzing Blinkit’s sales performance, customer satisfaction, and inventory distribution using interactive Power BI dashboards. The goal is to uncover trends, identify top-performing product categories, evaluate outlet performance, and provide data-driven insights for business optimization.
